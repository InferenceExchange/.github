# Contributing

Thank you for your interest in the Inference Exchange Protocol. This
guide applies to all repositories in the InferenceExchange
organization.

## Where things happen

- **Issues and pull requests** — bugs, changes, and proposals, in the
  relevant repository.
- **[Discussions](https://github.com/orgs/InferenceExchange/discussions)** —
  questions, ideas, and design conversations.
- **<inference-exchange-contact@googlegroups.com>** — private contact
  only: code-of-conduct reports and administrative inquiries. Not a
  discussion list.

## How to contribute

1. For substantial changes — protocol semantics, new interfaces, new
   repositories — open an issue or discussion first and agree on the
   direction before writing code or specification text.
2. Keep pull requests small and focused; one change per PR.
3. Every pull request needs a maintainer review. See
   [GOVERNANCE.md](GOVERNANCE.md) for how decisions are made.

## Sign your work

We use the [Developer Certificate of Origin](https://developercertificate.org/)
(DCO). By signing off you certify that you have the right to submit
your contribution under the project license.

Add a sign-off to each commit:

```
git commit -s
```

which appends:

```
Signed-off-by: Your Name <your.email@example.com>
```
