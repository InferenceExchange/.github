# .github

Community defaults for the
[InferenceExchange](https://github.com/InferenceExchange) organization.

This repository holds:

- [profile/README.md](profile/README.md) — the organization profile
  shown at [github.com/InferenceExchange](https://github.com/InferenceExchange)
- [GOVERNANCE.md](GOVERNANCE.md) — how decisions are made
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) — community standards
  (Contributor Covenant 3.0)
- [CONTRIBUTING.md](CONTRIBUTING.md) — how to contribute

`CODE_OF_CONDUCT.md` and `CONTRIBUTING.md` are GitHub
[default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file):
they apply to every repository in the organization that does not
override them.

This repository is also the source for the organization-wide
[Discussions](https://github.com/orgs/InferenceExchange/discussions).
